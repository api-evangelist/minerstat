We are introducing a new version of ASIC Hub. The older ASIC Hub 2.0 version worked only as a CLI for Linux, Mac, and Raspberry Pi devices, which was efficient but harder to maintain and manage. The new ASIC Hub 3.0 version is based on Graphical User Interface (GUI) and is besides Mac, Linux, and Raspberry Pi, supported for Windows
